# CI: GitHub Actions

Machine checked (2026-10-19). `.github/workflows/ci.yml`: 5-platform matrix
running the full `test.sh` (55 checks) per platform, plus a release job on
`v*` tags.

## Jobs (all green as of v0.1.0)

- **linux-x64 / linux-arm64** (ubuntu-24.04, ubuntu-24.04-arm): fully static
  `-static`, asserted via `ldd` = "not a dynamic executable".
- **macos-arm64 / macos-x64** (macos-15, macos-15-intel): macOS cannot link
  fully static — lexbor is a static archive; `otool -L` asserts only
  `/usr/lib/` and `/System/Library/` remain. (macos-13 Intel jobs never get
  scheduled; macos-15-intel is the working Intel label.)
- **windows-x64** (windows-2022, MinGW `-static`): works after porting
  (below). The POSIX save guarantees are documented as reduced on Windows
  (no O_NOFOLLOW dir walk, no mode preservation; temp+MoveFileEx atomicity
  kept).

## Compiler strategy

Tests need a DSL v5 compiler. `scripts/select-compiler.sh` probes by
compiling a real chunk and requiring `DSLB\x00\x05`. CI installs
**npm @lmctl-ai/lmctl@0.2.347**, whose bundled `lmscript` has
`DSL_VERSION = 5` (verified locally: the whole 55-check suite passes with
it on PATH). The mono `dsl.ts` adapter stays the fallback (needs Node ≥ 22
and a `~/lmctl-mono` checkout; the mono repo is not reachable with the
default GITHUB_TOKEN).

## What the matrix caught (13 push rounds)

- bash 3.2 on macOS: `"${EMPTY_ARRAY[@]}"` under `set -u`.
- pwsh silently no-op'ing the sync step on Windows → `defaults.run.shell: bash`.
- CMake `"Clang"` matches AppleClang: macOS got `-static` and died at link.
- git CRLF checkout breaking `sdk.lock` sha256 → `.gitattributes` `* eol=lf`.
- MSVCRT text mode translating `\n` → `\r\n` on stdout, breaking
  `--schema --json` byte identity → `_setmode(_O_BINARY)`.
- MinGW has no `openat`/`O_NOFOLLOW`/`unlinkat`/`fchmod` → ported save path.
- Windows path separators: `load_dir` findings use backslashes →
  `generic_string()` everywhere the DSL sees paths; output-root containment
  compared `\` vs `/`; drive-letter absolute globs; 8.3 short TEMP names.
- git-bash `/tmp` paths unreadable by the native host; Node compiler cannot
  resolve them either → `pwd -W` native WORK/schema paths in test.sh.
- macOS `/var` symlink breaking the absolute-glob prefix check (pwd -P).
- Not portable per-OS and skipped there: `ulimit -f` short-write,
  chmod-000 unreadable dir, POSIX file modes, APFS/NTFS case-insensitivity
  (link-policy expectation adapts at runtime).
