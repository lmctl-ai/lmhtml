# CI: GitHub Actions

Machine checked (2026-10-19). `.github/workflows/ci.yml`: 5-platform matrix
running the full `test.sh` (56 checks) per platform, plus a release job on
`v*` tags.

## Jobs (green in the v0.1.0 release workflow)

- **linux-x64 / linux-arm64** (ubuntu-22.04, ubuntu-22.04-arm): dynamic system glibc
  (minimum 2.35), with static libstdc++/libgcc and Lexbor; `readelf` checks the
  dynamic allowlist.
- **macos-arm64 / macos-x64** (macos-15, macos-15-intel): macOS cannot link
  fully static — lexbor is a static archive; `otool -L` asserts only
  `/usr/lib/` and `/System/Library/` remain. (macos-13 Intel jobs never get
  scheduled; macos-15-intel is the working Intel label.)
- **windows-x64** (windows-2022, MinGW `-static`): works after porting
  (described below). `Html.save` on Windows, exactly (implementation change, compile-checked
  with a MinGW cross compiler; the Windows-only test runs in CI):
  - kept: root containment check on canonical paths (a case difference
    can only cause a false refusal, never an escape); fresh `CREATE_NEW`
    temp name per save (a planted symlink/junction there fails creation
    instead of redirecting it — the first port used a predictable name
    opened with ofstream, i.e. the POSIX hole again); `FlushFileBuffers` +
    `MoveFileExW(REPLACE_EXISTING|WRITE_THROUGH)` (atomic on one NTFS
    volume); wide-char APIs (the first port used `MoveFileExA`, ANSI code
    page); refusal of device names (`CON`, `nul.html`, `COM1`…), alternate
    data streams (`a.html:x`), trailing dots/spaces and `<>"|?*`.
  - lost vs POSIX: no reparse-point-free directory walk, so a directory
    swapped for a junction between the check and the write can redirect it
    (TOCTOU, needs a local attacker racing the run); file mode/ACLs/owner
    of a replaced file are not carried over; 8.3 short names and
    `\\?\` device paths rely on canonicalization (existing parts resolve
    to long names; mismatched forms are refused, not escaped).

## Compiler strategy

Tests need a DSL v5 compiler. `scripts/select-compiler.sh` probes by
compiling a real chunk and requiring `DSLB\x00\x05`. CI installs
**npm @lmctl-ai/lmctl@0.2.420**, whose bundled `lmscript` has
`DSL_VERSION = 5` (verified locally: the whole 56-check suite passes with
it on PATH). The source adapter is optional and requires an explicitly configured `LMSCRIPT_SOURCE`; CI uses the published compiler.

## What the matrix caught (development iterations)

- bash 3.2 on macOS: `"${EMPTY_ARRAY[@]}"` under `set -u`.
- pwsh silently no-op'ing the sync step on Windows → `defaults.run.shell: bash`.
- CMake `"Clang"` matches AppleClang: macOS got `-static` and died at link.
- git CRLF checkout breaking `sdk.lock` sha256 → `.gitattributes` `* eol=lf`.
- MSVCRT text mode translating `\n` → `\r\n` on stdout, breaking
  `--dsl-schema --json` byte identity → `_setmode(_O_BINARY)`.
- MinGW has no `openat`/`O_NOFOLLOW`/`unlinkat`/`fchmod` → ported save path.
- Windows path separators: `load_dir` findings use backslashes →
  `generic_string()` everywhere the DSL sees paths; output-root containment
  compared `\` vs `/`; drive-letter absolute globs; 8.3 short TEMP names.
- git-bash `/tmp` paths unreadable by the native host; Node compiler cannot
  resolve them either → `pwd -W` native WORK/schema paths in test.sh.
- macOS `/var` symlink breaking the absolute-glob prefix check (pwd -P).
- Not portable per-OS and skipped there: `ulimit -f` short-write,
  chmod-000 unreadable dir, POSIX file modes, APFS/NTFS case-insensitivity
  (link-policy expectation adapts at runtime).

## Numbers

- Binary sizes (v0.1.0 release assets): linux-x64 **4,354,536 B**,
  linux-arm64 **4,212,112 B**, macos-x64 **1,794,928 B**,
  macos-arm64 **1,773,464 B**, windows-x64.exe **4,753,749 B**.
- Workflow configuration: build jobs `contents: read`, only the
  tag-gated release job `contents: write`; checkouts with
  `persist-credentials: false` (the build job runs third-party npm install
  scripts); actions pinned to commit SHAs; docs-only pushes skip the matrix;
  superseded branch runs cancelled. npm layout: `"private": true`,
  `UNLICENSED` (no LICENSE file in the repo), semver-only versions.
- Release binaries carry no secrets and no build paths (checked with
  `strings` on the v0.1.0 linux/macOS/windows assets; only basenames such
  as `value.c` and MinGW's relative `../../src/mingw-w64/...`). They are not
  stripped (symbols kept).
- Actions usage: ~5.7 job-minutes wall across 14 runs (never-started
  macos-13 jobs billed 0); billing depends on the repository plan and runner mix; check current usage in GitHub Actions billing. Release `v0.1.0` created with all five
  binaries attached; `npm-packages` artifact (esbuild-style layout via
  `scripts/npm-layout.sh`) generated, **not published**.
